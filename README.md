# Частная юридическая практика Марии

Одностраничный сайт Марии — частнопрактикующего юриста в Иркутске и дистанционно по всей России. На сайте представлены сроки, каталог документов, калькулятор, форма обращения и политика обработки персональных данных.

## Состав проекта

- `index.html` — структура страницы, интерактивные секции, форма и политика обработки ПДн.
- `styles.css` — адаптивная верстка и визуальная система.
- `script.js` — часы Иркутска, переключатели, сроки, каталог, калькулятор и форма.
- `send.php` — серверная проверка обращения, пересчет цены и запись в CSV.
- `.htaccess` — базовая защита конфигурационных файлов и заголовки.
- `data/.htaccess` — запрет доступа к журналу и служебным файлам.
- `images/` — локальные фотографии и изображение для Open Graph.

## Публикация

Для отправки настоящих заявок нужен веб-хостинг с PHP 8.0+ и Apache с поддержкой `.htaccess`. Скопируйте файлы сайта и папку `images/`, создайте каталог `data/` с правами записи для PHP. Не открывайте веб-доступ к каталогу `data/`; правило в `data/.htaccess` закрывает его на Apache.

При первой заявке обработчик создаст в `data/` криптографическую соль `.salt`, файл ограничения частоты и журнал `orders.csv`. Файлы должны быть недоступны на скачивание через веб. Используйте HTTPS, ограничьте доступ к файлам хостингом и регулярно проверяйте сроки хранения обращений.

Статический просмотр на GitHub Pages доступен в демонстрационном режиме. Форма показывает демо-статус только на домене `*.github.io`; заявка в этом режиме не отправляется и не сохраняется.

## Калькулятор

Итог сервера рассчитывается из допустимых идентификаторов документа, категории, формата и срочности. Переданная браузером сумма не является доверенной. Фронтенд и `send.php` используют прайс и формулу из `structure.md`.

В браузерном `localStorage` сохраняются только параметры калькулятора: `docType`, `disputeCategory`, `workFormat` и `urgency`. Имя, телефон, текст обращения и согласие не сохраняются в браузере.

## Обработка обращений

До публикации укажите актуальные сведения об операторе и контактах для обращений, утвердите срок хранения заявок, настройте права доступа и проверьте соответствие сайта требованиям ФЗ-152 и правилам выбранного хостинга. Текст политики в интерфейсе является основой для проверки, а не индивидуальным юридическим заключением.

Адреса судов и процессуальные сроки перед использованием следует сверять с официальными источниками и материалами конкретного дела. Расчет на сайте носит справочный характер и не гарантирует результат рассмотрения спора.

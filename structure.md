# Архитектура и спецификация проекта: Частная юридическая практика Марии (г. Иркутск + вся РФ)

## 1. Позиционирование и концепция

- **Продукт:** Коммерческий одностраничный сайт (Production Prototype) частнопрактикующего юриста **Марии**.
- **Формат наименования бренда:** Везде на сайте, в шапке, в карточках, в форме, в документах и в письмах юрист указывается исключительно по имени: **«Мария — частнопрактикующий юрист»** или **«Частная юридическая практика Марии»** (без использования фамилии).
- **География:**
  - **Очно и в судах:** г. Иркутск и Иркутский район (Кировский, Октябрьский, Свердловский, Ленинский, Куйбышевский районные суды г. Иркутска, Иркутский районный суд, Иркутский областной суд, Арбитражный суд Иркутской области, Четвертый арбитражный апелляционный суд).
  - **Дистанционно:** вся территория РФ (разработка процессуальных документов и электронная подача через ГАС «Правосудие», систему «Мой Арбитр», ФССП).
- **Специализация (Профиль):** Гражданское, арбитражное, семейное, наследственное, жилищное, земельное и административное право (ГПК РФ, АПК РФ, КАС РФ, КоАП РФ).
- **Вне профиля (Фильтр релевантности):** Уголовные дела (УК РФ / УПК РФ) не ведутся (выводится вежливое уведомление о специализации).
- **Главная идея:** Клиент приходит в состоянии стресса и дефицита времени (повестка в суд, судебный приказ, арест счета приставами, постановление ГИБДД). Сайт за 10 секунд дает спокойствие, ясность по процессуальным срокам, прозрачную стоимость и понятный план действий.

## 2. Визуальная система: Гибрид «Дело и печать + Швейцарская сетка» (C + A)

### Цветовая палитра (CSS Custom Properties)

- `--bg-paper: #F3EFE6` — основной фон (теплая гербовая/архивная бумага)
- `--bg-surface: #FAF7F0` — карточки, листы документов, модальные окна
- `--bg-elevated: #EAE3D5` — вторичные плашки, переключатели, ховеры
- `--bg-ink: #12161C` — глубокий чернильный фон (акцентные темные блоки, подвал)
- `--text-primary: #12161C` — основной чернильный текст
- `--text-secondary: #3A4048` — деловой графит (описания, подзаголовки)
- `--text-muted: #686E76` — пояснения, сноски, реквизиты
- `--accent-seal: #B8321E` — киноварь / сургучная печать (главный акцент, кнопки, штампы)

## 3. Файловая структура проекта

- `index.html` — Семантическая разметка (10 секций + модальное окно ПДн + липкая мобильная панель).

- `structure.md` — Архитектурная спецификация проекта.
- `CLAUDE.md` — Правила проекта для ИИ-агента.
- `README.md` — Документация проекта и инструкция по запуску.
- `.github/copilot-instructions.md` — Инструкции для GitHub Copilot.

### Секция 4. Интерактивный узел №1: «Радар процессуальных сроков + Фильтр профиля» (`#deadlines`)

  - Постановление ГИБДД / госоргана (ст. 30.3 КоАП РФ — 10 дней)

- Индикация остатка дней (Штатный режим / Горящий срок / Срок истек — требуется ходатайство о восстановлении срока по ст. 112 ГПК РФ).

## 5. Единая математическая модель калькулятора (Паритет `script.js` и `send.php`)

### Шаг 1. Базовая стоимость документа (`docType`)

- `order_cancel`: `3000` ₽ (Заявление об отмене судебного приказа / Ходатайство / Восстановление срока)
- `koap_kas`: `5000` ₽ (Жалоба по КоАП РФ / Административный иск на пристава по КАС РФ)
- `claim`: `7000` ₽ (Исковое заявление в суд по ГПК / АПК РФ)
- `objection`: `7000` ₽ (Возражение / отзыв на иск / Встречный иск)
- `appeal`: `10000` ₽ (Апелляционная / Кассационная жалоба)

### Шаг 2. Коэффициент категории спора (`disputeCategory`)

- `debt_contract`: `1.0` (Долги, договоры, расписки, неосновательное обогащение)
- `consumer`: `1.0` (Защита прав потребителей, услуги, застройщики)
- `auto_fssp`: `1.1` (ДТП, ОСАГО, ГИБДД и споры с приставами ФССП)
- `family_inherit`: `1.15` (Семейные и наследственные споры)
- `realty_land`: `1.25` (Недвижимость, жилищные и земельные споры)
- `arbitration`: `1.4` (Арбитражные споры ИП и юрлиц)

### Шаг 3. Надбавка за формат участия (`workFormat`)

- `doc_only`: `0` ₽ (Только документ + письменная инструкция по подаче)
- `doc_filing`: `2500` ₽ (Документ + дистанционная подача через ГАС «Правосудие» / «Мой Арбитр»)
- `turnkey_irkutsk`: `15000` ₽ (Под ключ с личным участием Марии в заседании суда г. Иркутска)

### Шаг 4. Множитель срочности (`urgency`)

- `standard`: `1.0` (Штатный режим: 2–4 рабочих дня)
- `urgent`: `1.3` (Горящий срок: 24 часа / завтра суд / последний день подачи)

### Формула расчета

1. `docCost = round((basePrice[docType] * categoryMult[disputeCategory]) / 100) * 100`
2. `subtotal = docCost + formatAddon[workFormat]`
3. `totalPrice = round((subtotal * urgencyMult[urgency]) / 100) * 100`

## 6. Требования безопасности и качества (Zero Review Bugs)

1. **Никаких ПДн в `localStorage`:** Хранить только неперсональные ключи калькулятора (`docType`, `disputeCategory`, `workFormat`, `urgency`).
2. **Строгая блокировка по чекбоксу ПДн:** Кнопка отправки формы и кнопки быстрого перехода в Telegram / WhatsApp неактивны (`disabled`), пока пользователь явно не поставит галочку согласия с Политикой ПДн.
3. **Серверная защита `send.php`:** Белые списки параметров, серверный пересчет `serverTotal`, honeypot `website`, rate-limit по IP с криптографической солью `data/.salt`, защита от CSV-инъекций (`csvSafe`), отсутствие HTML-сущностей в CSV, `flock(LOCK_EX)`.
4. **Честный демо-фолбэк:** Имитация успешной отправки при недоступности PHP разрешена строго только на доменах `*.github.io`.
